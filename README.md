# Візуалізатор підмереж (Subnet Visualizer)

Цей інструмент призначений для створення візуальних діаграм розподілу IP-адрес у підмережах. Він генерує графічне представлення вашої мережевої структури, що полегшує планування та документацію.

## Вимоги

Для роботи програми потрібен Python та бібліотека `matplotlib`.

Встановіть необхідні залежності за допомогою pip:

```bash
pip install -r requirements.txt
```

Або встановіть `matplotlib` вручну:

```bash
pip install matplotlib
```

## Використання

### 1. Запуск зі стандартними даними

За замовчуванням скрипт шукає файл `data.py` у поточній директорії. Щоб запустити генерацію діаграми:

```bash
python visualizer.py
```

### 2. Запуск з власним файлом даних

Ви можете вказати шлях до іншого файлу з даними за допомогою аргументу `-in` (або `--input`). Наприклад, щоб використати `example_data.py`:

```bash
python visualizer.py -in example_data.py
```

## Візуальний редактор (SubnetEditor.exe)

`editor.py` — редактор карти з інтерфейсом: карта оновлюється одразу після кожної зміни і виглядає точно так, як буде експортована (малюється тим самим кодом, що й `visualizer.py`).

*   **Мишею:** клік по блоку — вибрати групу; перетягнути блок — перемістити; перетягнути лівий/правий край — змінити розмір. Межі вирівнюються до кроку з поля «Прив'язка» (наприклад `/24`).
*   **Клавіатурою** (фокус на карті): `←`/`→` — зсунути групу, `Shift+←/→` — правий край, `Ctrl+←/→` — лівий край, `Delete` — видалити групу. Зручно для дуже вузьких блоків.
*   **Панель групи:** назва, коментар, колір, «показувати кожну підмережу окремо» та список підмереж (по одній у рядку) — можна правити вручну.
*   Після перетягування список підмереж групи перераховується в мінімальний набір вирівняних CIDR. Кнопка «Нормалізувати список» робить те саме вручну (наприклад, прибирає підмережі, що вкладені в інші).
*   **Попередження:** перекриття груп (червона штриховка на карті), некоректні підмережі, вихід за межі головної мережі.
*   **Дані:** відкриття/збереження `.py` (той самий формат, що читає `visualizer.py`) і `.json`. Файл `.py` лише читається як дані, код у ньому не виконується.
*   **Експорт:** PNG (300 dpi), PDF (A4, векторний, для друку), SVG; кольоровий або Ч/Б варіант, або обидва PNG одразу.
*   `Ctrl+Z`/`Ctrl+Y` — скасувати/повторити, `Ctrl+S` — зберегти, `Ctrl+O` — відкрити, `Ctrl+E` — експорт (працюють і з українською розкладкою).

Запуск з Python:

```bash
python editor.py                # відкриє останній файл
python editor.py data.py        # відкрити конкретний файл
python editor.py data.py --export map.pdf [--bw]   # експорт без вікна
```

### Збірка exe

```bash
pip install -r requirements.txt pyinstaller
build.bat
```

Результат — `dist\SubnetEditor.exe`, один файл, для запуску Python не потрібен. Перший запуск триває кілька секунд (exe розпаковується у тимчасову папку).

## Структура файлу даних

Файл даних (Python-скрипт) повинен містити наступні змінні:

*   **`main_subnet`** (str): Головна мережа у форматі CIDR (наприклад, `'192.168.0.0/16'`), яка буде відображена як основна шкала.
*   **`subnet_groups`** (list): Список груп підмереж. Кожна група — це словник з параметрами:
    *   `title` (str): Назва групи (або коментар, якщо `title` відсутній).
    *   `subnets` (list): Список підмереж (строки CIDR або словники з додатковими параметрами).
    *   `comment` (str, опціонально): Додатковий коментар.
    *   `show_full` (bool, опціонально): Чи показувати всі деталі підмереж.
    *   `color` (str, опціонально): Колір групи. Можна вказати назву або hex-код. Доступні назви:
        *   `red` - світло-червоний (#ff9999)
        *   `blue` - синій (#66b3ff)
        *   `light_blue` - світло-синій (#b3e0ff)
        *   `dark_blue` - темно-синій (#4d94ff)
        *   `green` - світло-зелений (#99ff99)
        *   `orange` - світло-оранжевий (#ffcc99)
        *   `purple` - світло-фіолетовий (#c2c2f0)
        *   `pink` - світло-рожевий (#ffb3e6)
*   **`map_title`** (str, опціонально): Заголовок, який буде відображено на діаграмі.

Приклад структури даних можна переглянути у файлі `example_data.py`.
