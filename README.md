# Візуалізатор підмереж (Subnet Visualizer)

Цей інструмент призначений для створення візуальних діаграм розподілу IP-адрес у підмережах. Він генерує графічне представлення вашої мережевої структури, що полегшує планування та документацію.

## Вимоги

Для роботи програми потрібен Python та бібліотека `matplotlib`.

Встановіть необхідні залежності за допомогою pip:

```bash
pip install -r requirements.txt
```

Або встановіть `matplotlib` вручну:

```bash
pip install matplotlib
```

## Використання

### 1. Запуск зі стандартними даними

За замовчуванням скрипт шукає файл `data.py` у поточній директорії. Щоб запустити генерацію діаграми:

```bash
python visualizer.py
```

### 2. Запуск з власним файлом даних

Ви можете вказати шлях до іншого файлу з даними за допомогою аргументу `-in` (або `--input`). Наприклад, щоб використати `example_data.py`:

```bash
python visualizer.py -in example_data.py
```

## Структура файлу даних

Файл даних (Python-скрипт) повинен містити наступні змінні:

*   **`main_subnet`** (str): Головна мережа у форматі CIDR (наприклад, `'192.168.0.0/16'`), яка буде відображена як основна шкала.
*   **`subnet_groups`** (list): Список груп підмереж. Кожна група — це словник з параметрами:
    *   `title` (str): Назва групи (або коментар, якщо `title` відсутній).
    *   `subnets` (list): Список підмереж (строки CIDR або словники з додатковими параметрами).
    *   `comment` (str, опціонально): Додатковий коментар.
    *   `show_full` (bool, опціонально): Чи показувати всі деталі підмереж.
*   **`map_title`** (str, опціонально): Заголовок, який буде відображено на діаграмі.

Приклад структури даних можна переглянути у файлі `example_data.py`.

## Результат

Після успішного виконання скрипт згенерує два зображення у поточній директорії:

*   `subnet_map.png` — Кольорова діаграма.
*   `subnet_map_bw.png` — Чорно-біла діаграма.
